# 牛马工作台

**个人电脑工作记录仪表盘** — 按开发 / 办公 / 健康 / 摸鱼四个范围，本地统计今日工作痕迹，并一键产出可配置范围的工作周报。

## 一句话

打开软件就能看到：今天代码改了多少、办公文档动了哪些、坐了多久、摸鱼摸了多久；周末点「周报」按配置范围出稿。

## 产品定位

- **形态**：Windows 便携桌面应用（Tauri 2 + Rust），托盘常驻 + 可选桌面挂件  
- **数据**：全部本机本地采集与存储，不上传  
- **人群**：以开发者为第一用户，结构按「工作范围」而非工具名划分，便于扩展到办公向角色  

## 主界面范围

| 页签 | 展示内容 |
|------|----------|
| **总览** | 今/周代码修改量（±行）、未提交、在线时长、健康分、近 7 天代码趋势 |
| **开发** | 仓库热力与分支同步、扩展名占比、未完成（脏文件）清单、周报面板 |
| **办公** | 办公文档今/周/月量、最近文档、类型构成、近 7 天产出、目录专注 |
| **健康** | 健康分、久坐/连续工作、键盘与碎片打断、前台应用、久坐托盘提醒 |
| **摸鱼** | 仅可量化时长：8h 未工作比例、有效工作、摸鱼合计、听歌、公众号阅读粗估、微信前台 |

> **摸鱼不写入周报**，仅供本机参考。

> **数据口径**：所有指标的来源与计算公式见 [CALC.md](./CALC.md)。修改统计逻辑时必须同步更新该文件。

## 周报

- 支持 **草稿 / 润色 / 历史 / 复制 / 导出 MD**  
- 章节按设置勾选范围输出：**开发 / 办公 / 健康**（`weekly_scope_*`）  
- 未启用的范围整节不出现；序号自动顺延  
- 开发口径：以 **±行（修改量）** 为主，提交次数为辅；扩展名可过滤；作者本机发现后勾选  

## 系统

- 开机自启静默进托盘（`--silent`）  
- 托盘：打开工作台、桌面小组件、立即采样、生成周报、自启、退出  
- 桌面挂件：今日代码/文件/健康等摘要，可拖拽、展开；**× 隐藏**（同步关闭挂件配置）  
- 可选诊断日志：`data/app.log`  

## 运行

```text
牛马工作台\牛马工作台.exe
```

同目录使用便携数据：`config.json`、`data\`、`weekly\`。

### 开发

```powershell
cd personal-workbench
# 或 cd C:\Users\...\牛马工作台\personal-workbench
pnpm install
pnpm tauri dev
# 发布
cd src-tauri
cargo build --release
# 产物 target/release/personal-workbench.exe，可复制为 牛马工作台.exe
```

## 目录结构

```text
牛马工作台/
├── 牛马工作台.exe          # 便携运行入口
├── config.json             # 配置（扁平字段）
├── data/                   # 运行数据（活动、焦点、历史等）
├── weekly/                 # 周报 Markdown
├── README.md
└── personal-workbench/     # 源码（Tauri 2）
    ├── src/                # 前端 index.html / app.js / styles.css / widget*
    └── src-tauri/src/      # Rust：git / weekly / health / slack / office / …
```

## 配置要点（设置）

| 页签 | 主要项 |
|------|--------|
| 开发 | 仓库扫描根、扫描深度、手动路径、Git 身份勾选、扩展名过滤、周报仓库、**开发写入周报** |
| 办公 | 扫描排除关键字、**办公写入周报** |
| 健康 | 空闲阈值、采样间隔、提醒、AI、**健康写入周报** |
| 系统 | 挂件、静默自启、启动是否开主窗、诊断日志 |

默认**不会扫全盘**，只扫用户目录下常见项目文件夹；发给他人使用时，请对方在设置里填写自己的扫描路径，并安装 Git。

## 设计约束（UI）

- 滚动条与整体深色界面一致（主题细滚动条），禁止系统默认亮色滚动条  
- 图表空值不渲染成大片空白色块
