# 牛马工作台

**个人电脑工作记录仪表盘 + 一键周报** — 打开就能看到今天/本周代码改了多少、文档动了哪些、坐了多久、摸了多久鱼；周末点一下，按你勾选的范围出周报。

> 源码 crate 名为 `personal-workbench`，界面与可执行文件名为 **牛马工作台**。  
> 全部指标的来源与计算公式见 **[CALC.md](./CALC.md)**（改统计逻辑必须同步该文档）。

## 为什么做这个产品

打工人（尤其是研发）每天的真实产出，散落在 Git 提交、Office 文件、工位前的连续坐班和琐碎切换里。到了写周报、汇报、复盘时，常见困境是：

1. **回忆不可靠** — 「这周到底改了多少、干了啥」靠印象，容易低估或写虚。
2. **口径不统一** — 有的地方数提交次数，有的地方数文件，领导问「工作量」对不上。
3. **健康被忽略** — 久坐、连续不离位，只有身体报警了才有感觉。
4. **周报耗时** — 周末再翻记录、整理结构，半小时到一小时就没了。
5. **隐私顾虑** — 市面工时/监控软件要么上传云端，要么按「工位摄像头/上网行为」管控，个人使用不放心。

**牛马工作台**的出发点：把「本机已有的工作痕迹」自动收成**可自用、可汇报**的视图，并一键变成周报草稿；数据只留在自己电脑上，**不上传、不监控他人**。

## 产品优势

| 优势 | 说明 |
|------|------|
| **本地隐私** | 全部采集与存储在本机便携目录，无账号、无云端同步 |
| **口径透明** | 每一项怎么算写在 `CALC.md`，可审计、可改、可同步 |
| **按工作范围组织** | 总览 / 开发 / 办公 / 健康 / 摸鱼 / 历史，而不是堆工具图标 |
| **周报可交付** | 草稿结构清晰；保留你手写的「下周计划 / 风险」；支持润色、复制、导出 MD |
| **摸鱼不进周报** | 休闲统计仅供本人参考，汇报材料干净 |
| **健康向提醒** | 「连续在座」为主指标（读屏/思考不断开），久坐托盘提醒 |
| **历史可回放** | 指标按日增量写入本地 SQLite，可选保留天数，**默认永久** |
| **便携免安装** | 单目录：`牛马工作台.exe` + `config.json` + `data\` + `weekly\` |
| **资源克制** | Tauri 2 + Rust，托盘常驻；默认只扫常见项目目录，**不扫全盘** |

## 核心能力

### 1. 开发量以「修改量」为准

- 主指标是 **+行 / −行**，提交次数只作副信息  
- 可按扩展名过滤（如只计 `sql,go,rs,js…`）  
- Git 作者：本机自动发现后勾选，不必手填邮箱列表  

### 2. 周报一键出稿

- 草稿 / 润色 / 历史 / 复制 / 导出 Markdown  
- 章节范围开关：**开发 / 办公 / 健康**（未勾选的整节不出现）  
- 重新生成时**保留**已填写的「下周计划、风险与依赖」  
- 中文提交关键词自动归类（功能 / 修复 / 优化…）  

### 3. 健康：连续在座而不是「必须一直敲键盘」

- 在座断开阈值可配（默认 6 分钟）；读文档、看屏幕短空闲**不断开**  
- 高置信在机：键盘 / 点击 / 鼠标位移均可计入  
- 健康分连续计分 + 久坐托盘提醒  

### 4. 总览时间范围

- 顶部切换：今日 / 本周 / 近 7 天 / 近 30 天 / 上周 / 本月 / 上月 / 自定义起止  
- **整页总览随范围变化**（代码、在机、在座、键入、前台、双色日柱），不再单独开「历史」块  
- 未提交、健康分始终为**当前实时**  

### 5. 数据长期保存

- 指标写入 **`data/metrics.sqlite`**（按日 UPSERT 增量）  
- 保留策略：`metrics_retention_days`，**0 = 永久（默认）**  
- 旧 JSON 镜像便于查看/备份；启动时自动迁入 SQLite

## 定位与边界

- **形态**：Windows 便携桌面应用（Tauri 2 + Rust），托盘常驻 + 可选桌面挂件  
- **人群**：以开发者为第一用户，结构按「工作范围」划分，便于扩展到办公向角色  
- **不做**：上网行为审计、他人监控、云端工时 SaaS、工位摄像头类「管控」  
- **办公历史**：按文件 mtime/ctime 近似，不是「当天碰过文件」的完整账本  
- **小时级时间轴**：当前未做逐小时归档（可后续扩展）

## 运行

**下载便携版**：[Releases](https://github.com/dafeng-001/Workhorse_Workstation/releases) → 取最新的 `Workhorse_Workstation-win64.exe`。

或本机直接运行：

```text
牛马工作台\牛马工作台.exe
```

每次发版可执行：

```powershell
powershell -File scripts\publish-release.ps1
# 指定 tag / 说明
powershell -File scripts\publish-release.ps1 -Tag v2026.09.22 -Notes '本周改动说明'
```

### 版本与发版

- **每次提交/发版：版本号末段 +1**（`2026.9.22` → `2026.9.23`）
- `scripts\bump-version.ps1` 同步 `Cargo.toml` 与 `tauri.conf.json`
- Release tag 为 **`v` + 版本号**（如 `v2026.9.23`）

```powershell
powershell -File scripts\bump-version.ps1
powershell -File scripts\publish-release.ps1 -Tag v2026.9.23 -Notes '说明'
```

### 在线更新

设置 → **系统 → 在线更新** →「检查更新」→「下载并更新」：对照 GitHub Releases 最新便携包，下载校验后自动替换 exe 并重启。  
当前内置版本号与 Release tag 对齐（如 `v2026.09.22`）。

同目录便携数据：

```text
config.json    # 配置
data\          # metrics.sqlite 与日表镜像 JSON
weekly\        # 周报 Markdown
```

### 开发构建

```powershell
cd personal-workbench
pnpm install
pnpm tauri dev

# 发布
cd src-tauri
cargo build --release
# 产物 target/release/personal-workbench.exe → 复制为 牛马工作台.exe
```

## 目录结构

```text
牛马工作台/
├── 牛马工作台.exe            # 便携运行入口（.gitignore，发行走 Release）
├── scripts/
│   └── publish-release.ps1   # 上传本机 exe 到 GitHub Release
├── config.json               # 配置（扁平字段）
├── data/                     # metrics.sqlite + 运行数据
│   ├── metrics.sqlite        # 指标主库（日表，可永久保留）
│   └── *.json                # 镜像/缓存/日志
├── weekly/                   # 周报 Markdown
├── README.md
├── CALC.md                   # 数据来源与计算规则（唯一口径说明）
└── personal-workbench/       # 源码（Tauri 2）
    ├── src/                  # index.html / app.js / styles.css / widget*
    └── src-tauri/src/        # Rust：git / weekly / health / slack / metrics_db …
```

## 配置要点（设置）

| 页 | 主要项 |
|----|--------|
| **开发** | 扫描根目录、深度、手动仓库、Git 身份勾选、扩展名过滤、周报仓库、开发写入周报 |
| **办公** | 扫描排除关键字、办公写入周报 |
| **健康** | 空闲阈值、采样间隔、**在座断开**、**数据保留（天，0=永久）**、提醒、AI 建议、健康写入周报 |
| **系统** | 挂件、静默自启、启动是否开主窗、诊断日志 |

默认**不扫全盘**，只扫用户目录下常见项目文件夹。发给他人使用时，请对方填写自己的扫描路径，并安装 Git。

## 设计约束（UI）

- 滚动条与深色主题一致（细滚动条），不用系统默认亮色滚动条  
- 图表空值不画成大片空白块  
- 周报预览用轻量 Markdown 渲染，复制/导出使用原始文本
