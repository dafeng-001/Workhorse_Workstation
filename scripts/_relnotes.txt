## v0.0.6 更新说明

### 新增 · AI 沟通页
- 顶部导航新增 **AI**：周报 / 健康 / 待办统一对话流
- 输入栏固定底部：`+` 上传健康数据、`/` 调用技能、模型状态、发送
- 预设动作：周报草稿/润色、健康本地/AI、本周待办
- `/待办` 拆条 → 确认卡 → 写入总览待办

### 新增 · 本地 Skill
- 便携目录 `skills\*.md`（frontmatter：id / name / triggers），可编辑覆盖
- 默认：健康建议、明日计划、周报口径
- 设置 → AI：可挂多个 **Skill 路径**，列表添加/删除

### 变更 · 功能归位
- 「健康提示 + 经方作息」合并为 **健康建议**（本地 / AI 同一功能）
- 周报草稿与「按配置范围出稿」**迁至 AI 页**「周报输出」抽屉；总览只留待办
- Token 配置从「健康」挪到 **设置 → AI**

### 新增 · 多界面风格
- 设置 → 系统 → 外观：午夜 / 青碧 / 紫罗兰 / 琥珀 / 浅色 / 浅蓝
- 可跟随系统深浅；主题写入 config.json 并即时生效
- 浅色下顶栏、按钮、边框、文字对比度专项修正
